# UCT Business Systems Analysis Portfolio

This repository contains assignments and practical deliverables completed as part of the Business Systems Analysis online short course offered by the University of Cape Town (UCT) through GetSmarter.

The portfolio demonstrates core Business Analysis and Systems Analysis competencies, including:

- Requirements Elicitation and Analysis
- Stakeholder Identification and Management
- Business Process Modelling (AS-IS and TO-BE)
- Business Requirements Documentation (BRDs)
- User Stories and Use Cases
- Functional and Non-Functional Requirements
- Gap Analysis
- Process Improvement
- Data and Information Modelling
- Solution Evaluation and Recommendation

This repository contains assignments completed across 10 course modules, showcasing the application of Business Systems Analysis techniques to real-world business scenarios.

## Skills Demonstrated:
- Business Analysis
- Systems Analysis
- Process Mapping
- Problem Solving
- Requirements Gathering
- Stakeholder Engagement
- Documentation
- Critical Thinking
- Solution Design
